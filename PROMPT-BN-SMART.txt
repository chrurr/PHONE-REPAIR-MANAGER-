أريد تحويل مشروع موقع EL ZAIME TELECOM المرفق إلى نسخة باسم BN SMART.

المطلوب فقط:
1. تغيير اسم المحل/العلامة التجارية من EL ZAIME TELECOM إلى BN SMART في جميع واجهات الموقع والعناوين والوصولات ورسائل WhatsApp وmanifest وأي نص ظاهر للمستخدم.
2. استعمال شعار BN SMART المرفق بدل الشعار القديم في الموقع وPWA.
3. الحفاظ على نفس التصميم والوظائف والمنطق وقاعدة البيانات وواجهات API والصلاحيات وطريقة العمل الموجودة في المشروع، بدون إضافة أي ميزة جديدة وبدون حذف أو تغيير أي ميزة موجودة.
4. المشروع Web فقط؛ لا تنشئ ولا تعدل تطبيق Android.
5. يجب أن يبقى المشروع قابلاً للتشغيل على Node.js/Express وPostgreSQL وعلى Render بنفس طريقة المشروع الأصلي.
6. لا تغيّر أسماء المسارات أو API أو بنية قاعدة البيانات إلا إذا كان تغيير اسم العلامة التجارية مطلوباً لذلك.
7. لا تغيّر بيانات المحل أو رقم الهاتف أو العنوان أو الصلاحيات أو الحسابات أو منطق الإصلاحات.

النتيجة المطلوبة: مشروع BN SMART جاهز للرفع إلى GitHub ثم النشر على Render، مع نفس وظائف المشروع الأصلي تماماً، والاختلاف فقط هو اسم BN SMART والشعار المرفق.
