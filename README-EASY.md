# BN SMART — تشغيل سهل

1. ثبّت Docker Desktop وشغّله.
2. افتح المجلد.
3. اضغط مرتين على `START-BN SMART.bat`.
4. سيفتح النظام تلقائياً في المتصفح على `http://localhost:3000`.

الدخول الأول:
- المستخدم: `admin`
- كلمة المرور: `Admin@12345`

غيّر كلمة المرور بعد أول دخول.

إيقاف النظام: `STOP-BN SMART.bat`
إعادة التشغيل: `RESTART-BN SMART.bat`

قاعدة PostgreSQL محفوظة في Docker Volume دائم.

للوصول من الهاتف على نفس Wi‑Fi: استخدم عنوان IP للكمبيوتر مع المنفذ 3000، مثل `http://192.168.1.10:3000`.

للوصول من أي مكان عبر الإنترنت، يحتاج المشروع إلى نشر على VPS/خادم مع دومين وHTTPS وتغيير JWT_SECRET وإعداد النسخ الاحتياطي والحماية.
