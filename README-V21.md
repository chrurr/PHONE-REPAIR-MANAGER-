# BN SMART TELECOM V21

V21 fixes the physical A6 receipt printed from the manager dashboard. The WhatsApp/customer share receipt remains unchanged.

The print receipt is a true A6 portrait page (105x148 mm), with the layout based on the customer's supplied paper receipt: logo/header, phone, receipt/customer/device/color rows, fault, accessories, QR/tracking, price/paid/remaining, warranty terms, and closing phrase.
